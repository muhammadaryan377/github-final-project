# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Push your branch to your fork.
6. Open a pull request describing your changes.

## Bug Reports and Bug Fixes

If you find a bug, please open an issue with a clear description of the problem and, if possible, steps to reproduce it. Bug fixes are welcome through pull requests.

## Documentation Improvements

Improvements to README files, comments, examples, and other documentation are welcome.

## Enhancements and Ideas

Suggestions for new features, usability improvements, and other enhancements are welcome. You may open an issue to discuss your idea before submitting a pull request.

Thank you for contributing!
